# Enemies

Place each authored enemy definition at `<enemy-id>/unit.js`, using the template in `../templates/`. Create its stat template in `data/stats/actors.csv`, regenerate stats, then register the definition in `units/catalog.js`. No enemies are registered yet.

This folder groups authoring work; hostility is not permanently determined by a folder. Relationships, memories, future faction rules and encounter behaviour can change an individual's allegiance. Do not create a duplicate unit when an existing NPC becomes hostile.
