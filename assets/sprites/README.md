# Character appearance sprites

Individual transparent PNGs for character appearance review and future animation work.

- `Humans/Male`: base plus six variants (7 sprites).
- `Humans/Female`: base, six trouser variants, and six dress variants (13 sprites).
- `Halflings/Male` and `Halflings/Female`: one base each.
- `Dwarves/Male` and `Dwarves/Female`: one base each.

These are single left-facing three-quarter idle poses. They are not animation sheets and are not yet connected to the game renderer. The halfling and dwarf appearance variations have not been created yet.

Human appearance catalogs are included beside their PNGs. Image canvas dimensions can vary slightly; preserve character proportions and align foot baselines when preparing animation sheets.
